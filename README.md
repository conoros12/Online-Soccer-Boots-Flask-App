# Soccer Boots E-Commerce App

A full-stack e-commerce web application for browsing and purchasing soccer boots.

The project was developed as part of my Computer Science coursework.

## Features

- User registration and login
- Product browsing
- Product search
- Shopping cart
- Wishlist functionality
- Product reviews
- Checkout functionality
- Customer functionality
- Admin functionality
- Relational database

## Technologies

- Python
- Flask
- SQLite
- SQL
- HTML
- CSS
- Jinja

## How It Works

The application uses Flask as the backend framework and SQLite as the relational database.

Users can browse products, search for soccer boots, add products to their cart or wishlist, and leave reviews.

The application also includes separate customer and administrator functionality.

## Database

SQLite is used to store application data including:

- Users
- Products
- Shopping carts
- Wishlists
- Reviews
- Orders

The database uses relationships between tables to manage the different parts of the application.
